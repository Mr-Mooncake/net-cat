TCP Chat Project — Checklist
============================

Goal: Recreate NetCat in Go as a TCP group chat (server + up to 10 clients).
Deadline: Sunday 04 Oct -> Wednesday 07 Oct (4 days), 3 members.
Methodology: Search first, try it yourself. Only if stuck, ask an AI and
learn what each line does. Don't keep code you can't explain.

Members:  A = server & connections   B = client session & welcome
          C = messages & broadcast
Names:    A: Mohammed Abu Hasan   B: Husain Hani Tammam   C: Baqer Alasmawi

Rules (read before starting)
- Go only. Packages: io, log, os, fmt, net, sync, time, bufio, errors,
  strings, reflect. (Tests need "testing" - confirm with your supervisor.)
- Must use goroutines AND channels or mutexes. Max 10 connections.
- Exact texts: [USAGE]: ./TCPChat $port | Listening on the port :8989 |
  [ENTER YOUR NAME]: | [YYYY-MM-DD HH:MM:SS][name]:message
- Edit only your own files. Want to rename an agreed function? Tell the team.
- One Git branch per member. Merge to main only when it builds.
- Shared data (clients, history) is always protected (mutex or channel).
- No bonus until every core box is ticked.

Folder structure
TCPChat/
  main.go            (A) run with: go run .
  go.mod             (A)
  server/
    server.go        (A)  server_test.go     (A)
    client.go        (B)  client_test.go     (B)
    banner.go        (B)
    message.go       (C)  broadcast_test.go  (C)
    history.go       (C)
    broadcast.go     (C)
  notes/             learning notes, one file per member
  logs/              used by a bonus task
