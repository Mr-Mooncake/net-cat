 SECTION 0 - HOW WE LEARN  (everyone reads this before touching any code)
==============================================================================
 These concepts are new to us, so the answers are NOT written in this plan.
 For every task, follow these steps in order:

   1. READ the task and its "Search hints".
   2. SEARCH on your own (Tour of Go, Go by Example, pkg.go.dev, man nc,
      YouTube, Stack Overflow). Time-box yourself: about 45-60 minutes per task.
   3. TRY to write it yourself, even if it is wrong or ugly. Run it. Read the error.
   4. STILL STUCK? Only now ask an AI. Rules:
        - Paste YOUR attempt and the error, not just the task.
        - Ask for an explanation line by line, not only the final code.
        - Ask "why" questions: why a goroutine here? why a mutex here?
   5. AFTER getting an answer: close it, then re-type the code yourself from
      understanding. Add a comment on each important line in your own words.
   6. Write 3-5 lines of what you learned in notes/member_X.txt.
   7. At the daily sync, say which parts you needed AI for, so the team studies them too.

 Golden rule: if you cannot explain a line to your teammates, the line is not done.
