TCP Chat Project — Bonus Checklist
==================================

Same methodology: search first, try it yourself, then ask an AI and learn
each line.

Rules (read before starting)
- Start only when every core box in CHECKLIST.txt is ticked.
- Never break the core: re-run the Final check after each bonus.
- One Git branch per bonus. Keep bonus code in new files where possible.
- Plain `nc` must still work. Same allowed packages as the core.
- Only exception: gocui (github.com/jroimartin/gocui), only for the
  Terminal UI. One person adds it to go.mod.
- Decide commands/flags as a team before coding, and write them down.
- 4 days is tight: do them in this order and stop when time runs out.

Bonus 1 — Logs saved to a file <A>
[ ] Decide what to log (joins, leaves, messages, errors)
[ ] Write to a file in logs/ with timestamps
[ ] Chat still works if the file can't be opened
Each peer does: look up log.New, os.OpenFile.

Bonus 2 — Clients can change their names <B>
Before you start: agree the command (e.g. what the user types).
[ ] The command is not broadcast as a normal message
[ ] Same name rules as the core
Each peer does: look up strings.HasPrefix, strings.Fields.

Bonus 3 — Group is told about a name change <B>
Before you start: Bonus 2 works.
[ ] Send the notice through C's broadcast functions
Each peer does: re-check how join/leave notices work.

Bonus 4 — More NetCat flags <A>
Before you start: read `man nc` and choose a few flags only.
[ ] Write the chosen flags here: ____________
[ ] Parse them; wrong flag -> usage message; core usage still works
Each peer does: look up man nc options, os.Args.

Bonus 5 — More than one group chat <C>
Before you start: plan on paper (commands, per-group history). Default
experience must stay the same.
[ ] Per-group clients and history, protected
[ ] Commands to create / join / leave / list groups
[ ] Join/leave notices only reach that group
Each peer does: look up maps of rooms with a mutex.

Bonus 6 — Terminal UI <B>
Before you start: do this last; check that gocui downloads on your machine.
[ ] Chat view + input view
[ ] Sending and receiving work; Ctrl+C closes cleanly
Each peer does: read the gocui README and examples.
